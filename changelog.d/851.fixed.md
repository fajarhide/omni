- **Redaction ends an unquoted shell value at whitespace, and looks at every assignment on
  the line (#851).** Everything after the first `=` was the value, so
  `APP_TOKEN=x ./bin/app serve &` was delivered as `APP_TOKEN=[REDACTED]` with the command
  gone and nothing saying so. The same rule read only the first assignment, so
  `APP_ROOT=/tmp/x APP_TOKEN=x ./bin/app` was delivered whole, token included. A line that
  opens with two or more `NAME=value` words, or with one followed by a word that can only
  start a command (`./`, `/`, `~/`, `\`, `&`), is now redacted word by word and counted per
  value. One assignment followed by a bare word is left to the old rule on purpose:
  `API_TOKEN=abc npm start` and `PASSWORD=correct horse` are the same shape, so that
  command is still lost rather than half a passphrase delivered. A quote anywhere on the
  line also keeps the old rule.
